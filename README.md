# Master React
Welcome to the Master React guide. Here you'll find a structured path to learning React effectively.

This guide will take you through the essential concepts and best practices in React, helping you build robust and maintainable applications.

## Getting Started

### Installation

Install the dependencies:

```bash
npm install
```

### Development

Start the development server with HMR:

```bash
npm run dev
```

Your application will be available at `http://localhost:5173`.
